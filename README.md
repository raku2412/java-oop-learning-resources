# Prüfungsvorbereitung – Programmierung II (OOP mit Java)

Eine Compose for Desktop Anwendung zur interaktiven Prüfungsvorbereitung für das Modul **"Programmierung II – Objektorientierte Programmierung mit Java"**.

## 📚 Beschreibung

Diese Anwendung unterstützt Studierende bei der Vorbereitung auf die Prüfung im Modul Objektorientierte Programmierung mit Java. Sie bietet thematisch geordnete Fragen im Single- und Multiple-Choice-Format, die eine gezielte Wiederholung und Selbstüberprüfung ermöglichen.

Die App wurde mit [JetBrains Compose for Desktop](https://www.jetbrains.com/lp/compose-multiplatform/) entwickelt.

## 🖥️ Features

- Interaktive Single- und Multiple-Choice-Fragen
- Zufällige Frageauswahl zur Selbstkontrolle
- Themenspezifische Kategorisierung
- Bewertung der Antworten nach "Abgabe"
- Einfache, fokussierte Benutzeroberfläche
- Mit IntelliJ IDEA ausführbar

## 🧩 Themengebiete

Die Fragen decken folgende prüfungsrelevante Kategorien ab:

- 🧱 **Objektklassen**
- 📦 **Programmbausteine und Pakete**
- 📚 **Java-API**
- 📊 **Felder (Arrays)**
- 🔢 **Aufzählungen (Enumerations)**
- 🧬 **Vererbung**
- 🌀 **Polymorphismus**
- ❗ **Ausnahme- und Fehlerbehandlung**
- 🔌 **Schnittstellen (Interfaces)**
- 🧪 **Generische Programmierung**
